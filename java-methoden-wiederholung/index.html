Wiederholung: Methoden

Aufgabe 1: Code-Analyse

Analysiere den folgenden Java-Quelltext.

public static double berechneRabatt(double preis, int prozent) {
    double rabattWert = (preis / 100) * prozent;
    return preis - rabattWert;
}

public static void druckeRechnung(String kundenName, double endPreis) {
    System.out.println("Hallo " + kundenName);
    System.out.println("Zu zahlen: " + endPreis + " Euro.");
}

public static void main(String[] args) {
    double basisPreis = 50.0;
    double neuerPreis = berechneRabatt(basisPreis, 20);
    druckeRechnung("Alex", neuerPreis);
}
  • a) Parameter: double, int. Rückgabetyp: double.
  • b) void bedeutet, die Methode gibt keinen Wert zurück. Der Aufruf erfolgt als eigenständiges Statement.
  • c) Ablauf: basisPreis wird definiert, berechneRabatt berechnet 40.0, druckeRechnung gibt aus:
    Hallo Alex
    Zu zahlen: 40.0 Euro.

Aufgabe 2: Fehlersuche

Gegeben ist die folgende Methodendeklaration für ein Login-System:

public static boolean ueberpruefePasswort(String nutzername, int pin) { 
    return true; 
}

Begründung der Fehler:

  • ueberpruefePasswort("User123", "Geheim123"): Zweiter Parameter erwartet int, erhält String.
  • ueberpruefePasswort(4567, "Max"): Parameter vertauscht (Typ-Mismatch).
  • ueberpruefePasswort("Anna"): Zu wenig Argumente übergeben.
  • int ergebnis = ...: Methode gibt boolean zurück, kann nicht in int gespeichert werden.

Aufgabe 3: Implementierung

Entwickle eine Methode berechneFahrpreis für einen E-Scooter-Verleih:

  • Parameter: int minuten, boolean isPremium
  • Rückgabewert: double
  • Logik: Preis = (minuten * 0.25) + (isPremium ? 0 : 1.00)
package wiederholung;

public class Methoden {
    public static double berechneFahrpreis(int minuten, boolean isPremium) {
        double preis = minuten * 0.25;
        if (!isPremium) {
            preis += 1.00;
        }
        return preis;
    }
}
