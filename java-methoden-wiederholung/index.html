Teil 1: Wiederholung Methoden (Parameter und Rückgabewerte)

1

Code-Analyse

Analysiere den folgenden Java-Quelltext.

public static double berechneRabatt(double preis, int prozent) {
    double rabattWert = (preis / 100) * prozent;
    return preis - rabattWert;
}

public static void druckeRechnung(String kundenName, double endPreis) {
    System.out.println("Hallo " + kundenName);
    System.out.println("Zu zahlen: " + endPreis + " Euro.");
}

public static void main(String[] args) {
    double basisPreis = 50.0;
    double neuerPreis = berechneRabatt(basisPreis, 20);
    druckeRechnung("Alex", neuerPreis);
}
  1. Nenne die Datentypen der Übergabeparameter sowie den Rückgabetyp der Methode berechneRabatt.
  2. Erkläre die Bedeutung des Schlüsselworts void im Methodenkopf von druckeRechnung und beschreibe die Konsequenz für den Aufruf dieser Methode.
  3. Beschreibe den Ablauf innerhalb der main-Methode schrittweise. Gib die exakte Konsolenausgabe an, die bei der Ausführung des Programms erzeugt wird.

Fehlersuche

Gegeben ist die folgende Methodendeklaration für ein Login-System:

public static boolean ueberpruefePasswort(String nutzername, int pin) { 
    // Logik zur Überprüfung
    return true; 
}

Die folgenden vier Methodenaufrufe innerhalb einer main-Methode sind fehlerhaft und führen zu Kompilierfehlern. Begründe für jeden der vier Aufrufe präzise die Fehlerursache. Beziehe dich dabei auf die übergebenen Parameter oder den Rückgabewert.

  • x ueberpruefePasswort("User123", "Geheim123");
  • x ueberpruefePasswort(4567, "Max");
  • x ueberpruefePasswort("Anna");
  • x int ergebnis = ueberpruefePasswort("Tom", 9999);

Implementierung

Berücksichtige dabei die folgenden Vorgaben:

  • -
    Übergabeparameter:

    Rückgabewert:

Teil 2: Vertiefung Arrays

Das Sieb des Eratosthenes

Eine Primzahl ist eine natürliche Zahl, die genau 2 unterschiedliche Teiler hat: Die 1 und die Zahl selbst. Um Primzahlen zu finden, kann man das folgende Verfahren durchführen, das sogenannte Sieb des Eratosthenes.

Fertige eine Liste oder Tabelle der natürlichen Zahlen bis zu einer beliebigen Größe an, zum Beispiel 100.

  • Zuerst wird die Zahl 1 gestrichen, da sie per Definition keine Primzahl ist.
  • Die Zahl 2 wird als Primzahl umkreist und dann alle Vielfachen von ihr gestrichen, da diese keine Primzahlen sein können.
  • Dann wird die nach der 2 nächste nicht gestrichene Zahl, die 3, umkreist und alle Vielfachen von ihr gestrichen.
  • Jetzt wird die nach der 3 nächste freie Zahl umkreist (die 5) und ihre Vielfachen gestrichen, usw.

Interaktives Zahlensieb

Tipp zur Bedienung: Mit einem Linksklick kannst du Zahlen durchstreichen (keine Primzahlen). Mit einem Rechtsklick kannst du Primzahlen einkreisen.

Perfekt! Du hast alle Primzahlen korrekt gefunden und den Rest durchgestrichen.

Aufgabe 1

Finde mit dem Sieb des Eratosthenes alle Primzahlen bis 100.

Aufgabe 2

Welche Datenstrukturen (Arrays, Variablen) und Kontrollstrukturen (Verzweigungen, Schleifen,...) werden benötigt, um das Sieb des Eratosthenes in Java zu programmieren?

Bonus-Aufgabe

Es sollen die Primzahlen bis zu einer Zahl $n\in\mathbb{N}$ bestimmt werden. Begründe, warum man bereits alle Primzahlen bis n gefunden hat, sobald die Vielfachen aller Zahlen bis $\sqrt{n}$ gestrichen wurden.
