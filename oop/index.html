Monster Arena

Objektorientierte Programmierung (OOP) in Java verstehen

1. Das Bauplan-Prinzip (Klassen)

In der OOP ist eine Klasse ein Bauplan. Stell dir vor, du entwirfst ein Monster für ein Spiel. Du legst fest, welche Eigenschaften (Attribute) und Fähigkeiten (Methoden) jedes Monster haben soll.

Ein Objekt ist eine konkrete Ausprägung (Instanz) dieses Bauplans - also ein echtes Monster in der Arena.

public class Monster { // Attribute (Eigenschaften) String name; int hp; int schaden; // Konstruktor public Monster(String n, int h) { this.name = n; this.hp = h; } // Methode (Fähigkeit) void attackieren(Monster ziel) { ziel.hp -= this.schaden; } }

2. Die Arena: Instanziierung & Interaktion

Erstelle zwei Objekte der Klasse Monster und lass sie gegeneinander antreten. Jedes Mal, wenn du auf "Angriff" klickst, wird eine Methode auf einem Objekt aufgerufen.

3. Quick-Check: OOP Konzepte

Was passiert bei der Anweisung Monster m1 = new Monster();?

Es wird ein neuer Bauplan (Klasse) erstellt.
Es wird eine neue Instanz (Objekt) der Klasse Monster im Speicher angelegt.
Das Programm löscht alle Monster-Daten.

Zusammenfassung für die Klausur

Klasse Bauplan für Objekte. Definiert Attribute und Methoden.

Objekt Eine konkrete Instanz einer Klasse.

Attribut Variable innerhalb einer Klasse (Zustand).

Methode Funktion innerhalb einer Klasse (Verhalten).

Konstruktor Spezielle Methode zur Initialisierung eines Objekts (new).

Kapselung Schutz von Daten vor direktem Zugriff (private/public).
